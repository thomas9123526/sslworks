# 사용자 인수 테스트 계획

**프로젝트:** vLearn2 (VFLS) · **버전:** 1.0 · **작성일:** 2026-05-22

---

## 1. 목적

본 계획은 릴리스 전 vLearn2가 사용자 기대에 부합하는지 검증하는 방법을
정의한다. 테스트 명세서가 시스템을 *기술적으로* 검증한다면, 사용자
인수 테스트(UAT)는 시스템이 실제 학습자와 운영 인력에게 *사용에
적합*함을 확인한다.

## 2. 범위

UAT는 두 대상 모두에 대해 실제 기기에서 종단간 여정을 다룬다.

- **학습자 UAT** — Android 및 Windows의 Flutter 앱.
- **운영 인력 UAT** — 브라우저의 관리자 패널.

범위 밖: 코드 수준 테스트(테스트 명세서가 다룸)와 DataManage 도구의
내부 메커니즘.

## 3. 참여자 및 환경

| 역할 | 책임 |
|------|------|
| UAT 코디네이터 | 세션 일정, 결과 기록, 사인오프 결정 |
| 학습자 테스터(2명 이상) | 실제 학습자로서 앱 사용 |
| 운영 인력 테스터(1명 이상) | 관리자 패널 사용 |
| 엔지니어링 지원 | UAT 중 발견된 이슈 분류 |

**환경:** 프로덕션을 대표하는 스테이징 배포(nginx, 실제 백엔드, 시드
콘텐츠, 스텁 또는 예산 책정된 AI 제공자). 최소 Android 기기 1대
(구버전 + 현재 SDK)와 Windows PC 1대.

## 4. 진입 기준

- 테스트 명세서의 모든 P1 케이스 통과.
- 미해결 S1/S2 결함 없음.
- 스테이징이 배포·접근 가능; 시드 콘텐츠 적재됨.
- 테스트 계정 존재(학습자, 서브 관리자, 슈퍼관리자).

## 5. 종료 / 사인오프 기준

- 아래의 모든 UAT 시나리오가 **통과**(또는 코디네이터가 수용한 **경미
  이슈 동반 통과**) 결과를 가짐.
- 미해결 S1/S2 결함 없음.
- UAT 코디네이터가 공식 사인오프를 기록.

## 6. 학습자 인수 시나리오

| ID | 시나리오 | 기대 결과 |
|----|----------|-----------|
| UAT-L1 | 설치, 가입, 온보딩 완료 | 계정 생성됨; 온보딩이 한 번 표시됨 |
| UAT-L2 | 로그인; "계정 기억" 후 앱 재실행 | 자격 증명 재입력 없이 로그인 상태로 복귀 |
| UAT-L3 | 채팅 모드 자유 회화 시작, 여러 턴 교환 | 튜터 응답이 일관됨; 메시지가 영속됨 |
| UAT-L4 | 시나리오 역할극을 완료하고 세션 종료 | 세션 리포트가 점수·강점·XP 표시 |
| UAT-L5 | 얼굴 모드 사용 | 애니메이션 튜터가 응답; 회화 동작 |
| UAT-L6 | 마이크로 말하기(모델 설치됨) | 음성 인식됨; 음성 응답 재생 |
| UAT-L7 | 모델 미설치 상태로 말하기 회화 시작 | 앱이 설정으로 안내; 텍스트 전용으로 깔끔히 계속 |
| UAT-L8 | 시나리오와 코스 탐색; 시나리오 브리프 열기 | 카탈로그와 브리프가 올바르게 표시 |
| UAT-L9 | 여러 세션 후 진행도 조회 | XP·레벨·streak·스킬·업적이 활동 반영 |
| UAT-L10 | 뉴스 읽고 해제 | 미읽음 수 갱신; 게시물 읽음 처리 |
| UAT-L11 | 프로필 편집; 테마·언어 변경 | 변경 적용·유지됨 |
| UAT-L12 | 비밀번호 변경 후 재로그인 | 기존 비밀번호 거부; 새 비밀번호 동작 |
| UAT-L13 | 오프라인(비행기 모드)으로 앱 사용 | 캐시 콘텐츠 표시; 명확한 오프라인 안내, 원시 오류 없음 |
| UAT-L14 | Android와 Windows 모두에서 실행 | 두 플랫폼에서 동등한 동작 |

## 7. 운영 인력 인수 시나리오

| ID | 시나리오 | 기대 결과 |
|----|----------|-----------|
| UAT-S1 | 관리자 패널 로그인 | 요약 통계가 있는 대시보드 |
| UAT-S2 | 시나리오 생성·편집·게시 후 보관 | 상태 전이 정확; 게시 시 학습자에게 노출 |
| UAT-S3 | 시나리오 이미지 업로드 | 유효 이미지 수락; 초과/무효 거부 |
| UAT-S4 | 페르소나 생성·편집 | 페르소나가 학습자에게 노출 |
| UAT-S5 | 사용 중인 카테고리 삭제 시도 | 명확한 메시지와 함께 삭제 거부 |
| UAT-S6 | 뉴스 게시물 생성·게시 | 게시물이 학습자에게 노출 |
| UAT-S7 | AI 프롬프트 템플릿 편집 | 변경이 새 회화에 적용 |
| UAT-S8 | 학습자 검색; 정지 후 복원 | 정지된 학습자 차단; 복원 시 재활성화 |
| UAT-S9 | (슈퍼관리자) 서브 관리자 생성·권한 부여 | 서브 관리자가 허용된 작업만 봄 |
| UAT-S10 | 서브 관리자가 권한 없는 작업 시도 | 작업 불가/거부 |
| UAT-S11 | 위 작업 후 감사 로그 검토 | 모든 변경이 행위자·세부 정보와 함께 기록됨 |
| UAT-S12 | 런타임 구성 플래그 변경 | 플래그 변경이 학습자 앱에 반영 |

## 8. UAT 중 결함 처리

- 이슈는 심각도(S1–S4), 시나리오 ID, 단계, 환경과 함께 기록한다.
- S1/S2 이슈는 사인오프를 차단하며 수정·재테스트된다.
- S3/S4 이슈는 후속 티켓과 함께 코디네이터가 수용할 수 있다.

## 9. 일정 (템플릿)

| 단계 | 기간 | 활동 |
|------|------|------|
| 준비 | — | 스테이징·계정·기기 프로비저닝 |
| 학습자 UAT | — | UAT-L1…L14 실행 |
| 운영 인력 UAT | — | UAT-S1…S12 실행 |
| 결함 수정 & 재테스트 | — | S1/S2 해결, 재테스트 |
| 사인오프 | — | 코디네이터가 결정 기록 |

기간은 릴리스별로 UAT 코디네이터가 설정한다.
