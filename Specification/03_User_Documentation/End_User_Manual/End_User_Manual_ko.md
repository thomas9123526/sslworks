# 사용자 매뉴얼

**제품:** Virtual Foreign Language (VFLS) · **버전:** 1.0
**대상:** Android 또는 Windows에서 앱을 사용하는 학습자.

---

## 1. 환영합니다

Virtual Foreign Language는 AI 튜터 캐릭터와 회화를 나누며 영어를
연습하도록 돕습니다. 자유롭게 대화하거나 가이드형 역할극 시나리오를
따를 수 있으며, 매 회화 후 말하기 능력에 대한 피드백을 받습니다.

## 2. 시작하기

### 2.1 설치 및 실행

Android 기기 또는 Windows PC에 앱을 설치하고 실행합니다. 앱이 준비되는
동안 스플래시 화면이 표시됩니다.

### 2.2 계정 생성

처음 사용 시 **회원가입**을 누르고 요청된 정보를 입력합니다. 비밀번호는
최소 6자로 설정합니다. 이미 계정이 있다면 **로그인**을 누릅니다. 다음
로그인을 빠르게 하기 위해 앱이 계정을 기억하도록 선택할 수 있습니다.

### 2.3 온보딩

첫 로그인 후 짧은 온보딩이 앱을 소개합니다. 한 번만 표시됩니다.

## 3. 주요 화면

앱에는 5개의 주요 탭이 있습니다.

| 탭 | 용도 |
|-----|------|
| **홈** | 시작 지점 — 추천 및 빠른 작업 |
| **시나리오** | 카테고리·난이도별 역할극 연습 탐색 |
| **이력** | 과거 회화 |
| **진행도** | 스킬, streak, 레벨, 업적 |
| **설정** | 계정, 외관, 환경설정 |

## 4. 회화하기

### 4.1 회화 시작

1. **튜터 페르소나**를 선택합니다 — 각기 다른 억양과 스타일을 가집니다.
2. 선택적으로 구조화된 역할극을 위해 **시나리오**를 고릅니다. 없으면
   자유 회화가 됩니다.
3. 모드를 선택합니다.
   - **채팅** — 텍스트 회화.
   - **얼굴** — 애니메이션 튜터 아바타와 대화.

### 4.2 회화 중

- 메시지를 입력하거나 마이크로 음성을 사용합니다(§5 참조).
- 튜터가 응답합니다. 자연스럽게 회화를 이어갑니다.
- 무슨 말을 할지 모르겠다면 **추천**을 요청합니다.
- 끝나면 **종료**를 누릅니다.

### 4.3 회화 후

다음을 담은 **세션 리포트**를 받습니다.

- 종합 점수 및 스킬별 점수(발음, 유창성, 어휘, 문법, 참여도, 듣기).
- 강점과 개선할 영역.
- 획득한 XP.

## 5. 음성으로 말하기

앱은 음성 입력과 음성 튜터 응답을 지원합니다. 음성 기능은 기기에
**음성 모델**이 설치되어 있어야 합니다.

- 말하기 회화를 시작할 때 모델이 설치되어 있지 않으면, 앱이 **설정
  화면**으로 안내합니다.
- 원하면 **텍스트 전용** 모드로 계속할 수 있습니다.
- 앱이 음성을 들을 수 있도록 요청 시 마이크 권한을 허용합니다.

## 6. 진행도, Streak, 업적

- **XP와 레벨** — 활동으로 XP를 얻고, XP가 레벨을 올립니다.
- **Streak** — 연속된 날에 연습하면 streak이 쌓입니다.
- **스킬** — 진행도 탭에서 스킬이 시간에 따라 어떻게 변하는지 봅니다.
- **업적** — 마일스톤에 도달하여 업적을 잠금 해제합니다.

## 7. 시나리오와 코스

- **시나리오**는 목표와 핵심 표현을 가진 개별 역할극 연습입니다. 각각
  예상 시간과 XP 보상을 표시합니다.
- **코스**는 시나리오를 순서가 있는 학습 경로로 묶습니다.
- 시나리오를 완료하면 최고 점수가 기록됩니다.

## 8. 뉴스

뉴스 섹션은 공지와 업데이트를 표시합니다. 미읽음 게시물이 표시되며,
게시물을 읽음으로 표시할 수 있습니다.

## 9. 설정

설정 탭에서 다음을 할 수 있습니다.

- **프로필** 편집 — 표시 이름, 아바타, 성별, 언어.
- **비밀번호** 변경(현재 비밀번호를 입력해야 합니다).
- **테마**, **폰트**, 채팅 말풍선 스타일 선택.
- 기본 회화 모드 설정.

## 10. 오프라인 사용

기기가 연결을 잃어도 앱은 로컬 캐시에서 이전에 로드한 콘텐츠
(시나리오, 이력, 진행도)를 계속 표시합니다. 네트워크가 필요한 작업
— 회화 시작, 메시지 전송 — 은 연결을 필요로 합니다. 오프라인일 때
앱은 기술적 오류 대신 명확한 메시지를 표시합니다.

## 11. 문제 해결

| 문제 | 조치 |
|------|------|
| 로그인 불가 | 자격 증명과 네트워크 확인; 비밀번호는 대소문자 구분 |
| "음성 모델 미설치" | 설정 화면을 따르거나 텍스트 전용 모드로 계속 |
| 마이크 작동 안 함 | 기기 설정에서 마이크 권한 허용 |
| 회화가 느림 | 앱이 네트워크를 기다리는 중일 수 있음; 더 나은 연결에서 재시도 |
| 앱이 오래된 데이터 표시 | 오프라인 상태일 수 있음; 재연결하여 새로 고침 |

## 12. 개인정보 안내

회화는 튜터링과 채점을 제공하기 위해 처리됩니다. 계정과 환경설정은
설정 탭에서 관리합니다.
