# 릴리스 노트

**제품:** Virtual Foreign Language (VFLS)

---

## 버전 1.0.0 — 2026-05-22

지원 백엔드와 관리자 콘솔을 갖춘, Android·Windows용 회화 중심 언어
학습 플랫폼 vLearn2(VFLS)의 첫 릴리스.

### 주요 기능

- **AI 회화 연습** — 페르소나 기반 튜터와 텍스트 **채팅** 모드 및
  애니메이션 **얼굴** 모드.
- **구조화된 시나리오** — 난이도별로 등급화되고 **코스**로 묶임.
- **자동 다중 스킬 채점** — 종합 및 발음·유창성·어휘·문법·참여도·
  듣기 — 매 회화 후 세션 리포트 제공.
- **진행도 및 게임화** — XP, 레벨, streak, 일별 스킬 스냅샷, 업적.
- **기기 내 음성** — 설치 가능한 서명 모델 번들을 통한 음성 인식 및
  음성 합성.
- **오프라인 읽기 모드** — 캐시된 콘텐츠가 연결 없이도 이용 가능.
- **뉴스** — 학습자별 읽음 추적이 있는 인앱 공지.
- **관리자 콘솔** — 콘텐츠 관리(시나리오, 페르소나, 카테고리, 코스,
  뉴스), 사용자 관리, AI 프롬프트 템플릿, 런타임 구성, 리더보드,
  감사 로그.

### 플랫폼

- Android(최소 SDK 24).
- Windows 데스크톱.

### 아키텍처

- 백엔드: Node.js 22 기반 NestJS 11, PostgreSQL 16, TypeORM.
- 관리자 패널: Next.js 14.
- 앱: Riverpod 및 go_router를 사용한 Flutter 3.41(Dart 3.11).
- 리버스 프록시: nginx(`/vfls` → API, `/vAdmin` → 관리자 패널).

### 보안

- 회전식 1회용 리프레시 토큰을 가진 JWT 인증.
- bcrypt 비밀번호 해싱; 권한 기반 관리자 RBAC.
- 고정 CA에 대해 검증되는 서명 `.ddp` 음성 모델 번들.
- 속도 제한 및 보안 헤더.

### 알려진 한계

다음은 시스템 설계 명세서 §11에 문서화되어 있으며 해결이 계획되어
있다.

- 새 회화의 첫 튜터 메시지가 플레이스홀더이다; 세션 시작 경로의 완전한
  AI 연동이 진행 중이다.
- 검증된 `.ddp` 모델 번들이 설치될 때까지 기기 내 음성은 플레이스홀더
  엔진을 사용한다.
- 런타임 gzip 토글은 현재 비활성 상태이다(차단 스위치가 코드에서 비활성
  화됨).
- 관리자 부트스트랩 가입 라우트는 최초 설정을 위해 의도적으로 개방되어
  있으며 공개 배포 전 차단되어야 한다.
- Android 릴리스 빌드는 프로덕션 키스토어가 마련될 때까지 디버그 키로
  서명된다.
- 자동화 테스트 커버리지가 현재 제한적이다; 테스트 명세서에 따라 확장이
  계획되어 있다.

### 업그레이드 참고

본 릴리스는 최초 릴리스이므로 업그레이드 단계가 없다. 데이터베이스
스키마는 포함된 마이그레이션으로 구성되며, 참조 콘텐츠를 적재하려면
시드 단계를 실행하라.
