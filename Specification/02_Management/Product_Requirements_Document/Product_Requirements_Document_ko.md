# 제품 요구사항 문서

**프로젝트:** vLearn2 (VFLS) · **버전:** 1.0 · **작성일:** 2026-05-22

기술 요구사항 명세서(SRS)에 대한 비즈니스·제품 관점의 동반 문서이다.
SRS가 `FR/NFR` 요구사항을 열거한다면, 본 PRD는 *이유*를 기술한다:
목표, 사용자, 우선순위, 성공 척도.

---

## 1. 제품 요약

vLearn2 — 제품명 *Virtual Foreign Language*(VFLS) — 는 AI 튜터
페르소나와의 회화를 통해 영어 말하기·쓰기를 연습하는 모바일·데스크톱
애플리케이션이다. 학습자는 자유롭게 또는 구조화된 역할극 시나리오를
통해 연습하고, 자동 다중 스킬 피드백을 받으며, 진행도 추적·연속
학습일·업적으로 동기를 유지한다.

## 2. 문제 정의

전통적인 언어 학습은 부담 없는 말하기 연습 기회가 제한적이다.
학습자는 인내심 있고 항상 이용 가능한 회화 상대가 없으며, 발음·유창성
·문법·어휘에 대한 구체적이고 다차원적인 피드백을 거의 받지 못한다.
vLearn2는 온디맨드 AI 회화와 자동 채점으로 이를 해결한다.

## 3. 목표와 비목표

### 3.1 목표

- 다양한 AI 튜터 페르소나와의 무제한·저부담 회화 연습 제공.
- 난이도별로 등급화되고 코스로 묶인 구조화된 시나리오 제공.
- 매 세션 후 실행 가능한 다중 스킬 피드백 전달.
- XP·레벨·streak·업적으로 동기 유지.
- 단일 코드베이스로 크로스 플랫폼(Android, Windows) 동작.
- 엔지니어링 개입 없이 운영 인력이 콘텐츠·사용자를 관리.

### 3.2 비목표 (현재 릴리스)

- 영어 외 언어.
- 실시간 인간 튜터링.
- 리더보드를 넘어서는 소셜/동료 기능.
- 결제 / 구독 청구.

## 4. 대상 사용자

| 세그먼트 | 설명 | 주요 니즈 |
|----------|------|-----------|
| 자기주도 학습자 | 독립적으로 영어 연습 | 자신감, 말하기 연습, 피드백 |
| 가이드 학습자 | 구조화된 경로를 따름 | 명확한 진행이 있는 시나리오·코스 |
| 콘텐츠 인력 | 시나리오·페르소나·뉴스 저작 | 효율적인 콘텐츠 도구 |
| 운영 인력 | 사용자·설정·거버넌스 관리 | 통제, 감사 가능성 |

## 5. 기능 우선순위

| 우선순위 | 기능 영역 |
|----------|-----------|
| P0(필수) | 계정/인증, AI 회화(채팅+얼굴 모드), 시나리오, 채점·세션 리포트, 진행도 추적 |
| P1(권장) | 코스, 업적, 뉴스, 기기 내 음성(STT/TTS), 오프라인 읽기 캐시, 관리자 콘텐츠 관리 |
| P2(선택) | 리더보드, 테마/폰트, 다중 UI 언어, 런타임 기능 플래그 |

## 6. 핵심 사용자 여정

1. **온보딩 & 첫 회화** — 가입 → 온보딩 → 페르소나 선택 → 자유 대화
   또는 시나리오 → 세션 리포트 수신.
2. **구조화된 연습** — 코스 탐색 → 시나리오 브리프 열기 → 역할극 완료
   → 점수·XP 확인 → 진행도 갱신.
3. **동기 유지** — 매일 연습으로 streak 연장 → XP가 레벨 상승 → 업적
   잠금 해제.
4. **운영 인력 콘텐츠 주기** — 시나리오 저작 → 아트워크 업로드 →
   게시 → 통계·감사 로그로 모니터링.

## 7. 성공 지표 (제안)

| 지표 | 의도 |
|------|------|
| 활성화 | 첫 회화를 완료한 신규 사용자 비율 |
| 참여 | 주간 활성 사용자당 세션 수; streak 길이 중앙값 |
| 학습 | 시간 경과에 따른 스킬별 스냅샷 점수 추세 |
| 유지 | 7일 및 30일 복귀율 |
| 콘텐츠 건전성 | 게시 시나리오 수; 시나리오 완료율 |
| 신뢰성 | AI 대체 경로를 포함한 회화 성공률 |

목표값은 측정 기준선이 마련되면 릴리스별로 설정해야 한다.

## 8. 제약 및 의존성

- 외부 AI 제공자(Anthropic 또는 OpenAI 호환)가 필요하며, 불가용 시
  우아하게 성능 저하한다.
- 기기 내 음성은 설치된 서명 `.ddp` 모델 번들을 필요로 한다.
- Android 최소 SDK 24; Windows 데스크톱.
- 백엔드는 nginx 뒤에서 Linux(RHEL 계열) 또는 Windows에 배포 가능하다.

## 9. 릴리스 범위 — v1.0

범위 내: Android·Windows용 모든 P0·P1 기능; 관리자 패널; 지원 백엔드.

v1.0으로 이월되는 알려진 한계(시스템 설계 명세서 §11 참조): AI 세션
시작 메시지가 플레이스홀더이다; 기기 내 음성은 모델 번들에 게이팅된다;
관리자 가입 라우트는 부트스트랩을 위해 개방되어 있으며 공개 출시 전
차단되어야 한다.

## 10. 미해결 질문

- 수익화 모델과 시점.
- 추가 대상 언어와 우선순위.
- 더 강한 기기 신원을 위한 기기별 등록 대 현재 공유 클라이언트 모델.
- 영어·중국어 UI를 넘어서는 지역화 범위.
